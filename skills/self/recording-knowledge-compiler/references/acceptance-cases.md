# 编译行为验收样本

维护本技能时，用以下匿名化、简化的来源片段检查实际成品。对照具体内容和状态判断，不按固定措辞、字数或关键词评分。结构校验器的通过不能代替这些行为验收。

## 1. 统计口径与经营事实

要求：编译为知识点讲义。

来源片段：

> 单位只要签一项就算续签。甲村和乙街道已续签，收入还是下降。网格一季度下降2000多元、二季度15000元、三季度26000元。季度降收超过500元的集团列清单跟进。

验收：保留续签计数口径、两个客户的状态、三季度各自数字及清单门槛和动作。正文直接表达这些事实，不能只剩“续签不等于收入保留”的提醒。

## 2. 简短案例与后续动作

要求：编译为指导手册中的业务拓展章节。

来源片段：

> 甲医院新拓等保是一次突破。走访大单位或有重要系统的企业，多问等保需求；已经有等保服务商的也可争取，比较价格。

验收：医院案例保留来源原有信息量，不补签约经过或收益；随后保留目标客户、询问需求、争取已有服务商客户和价格比较四项内容。

## 3. 姓名纠正与责任状态

要求：编译为会议文档。用户确认“王敏”应为“王珉”，已有资料确认客户经理身份，允许保留姓名。

来源片段：

> 王敏跟进甲企业，拟下周拜访。陈珊的乙企业项目已经签约，还没回款。会上建议王敏再联系丙企业。

验收：成稿保留王珉—甲企业的计划拜访、陈珊—乙企业的已签约未回款状态；联系丙企业仍是建议。纠错进入 `01`，覆盖表和书面稿同步，保存原始输入不改。没有给出的具体日期和回款期限不补写。

## 4. 片段范围与不同日期口径

要求：仅编译提供的会议中段转写，最终稿指定为知识点讲义；不追索其他片段。背景资料：9月国内版报价2万元。10月27日转写明确宣布国内版推广价1.68万元，回款后发酬金。

验收：仍交付讲义，保留10月27日推广价及回款条件，9月价格不静默覆盖新口径；只核验提供的区间，未录部分不进入待确认项或触发 `INSUFFICIENT_DATA`，范围说明留在覆盖表。
