# 04-external-views · 外部视角与批评

## 可能的优势

1. 能防止从宏大叙事直接跳到投资结论或政策结论。
2. 能把“增长”拆成生产、收入、分配、资产负债表和激励结构。
3. 能识别伪分析：堆名词、从结论找理由、没有反证标准。
4. 适合政治经济分析，因为政治经济问题经常涉及主体、激励、制度通道和分配结果。

## 可能的盲点

1. 过度机制化可能低估叙事、信念和合法性本身的经济作用。
2. 对短期市场定价来说，错误叙事也可能产生真实价格影响。
3. 机制链条很长时，证据成本高，容易陷入无限追问。
4. 如果只强调账户分配，可能低估公共品、外部性和长期制度能力。

## 使用时的校正

- 不要把“机制未证成”误判为“结论一定错误”。
- 对无法直接观测的机制，应标注为假设，并列出需要验证的数据。
- 政治经济分析要同时保留制度、阶层、组织、财政、金融和国际约束。
