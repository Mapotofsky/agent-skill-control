# 方法与视觉编码选择

在 `SKILL.md` 第三步中，当分析方法、数据表示或视觉形式需要判断时读取本文件。先按任务选择起点，再结合数据量、对象语义与行动需要组合方法。

## 任务选择表

| 判断任务 | 表示与分析起点 | 视觉表达起点 | 解释边界 |
| --- | --- | --- | --- |
| 比较对象高低或与基准的差距 | 同口径指标、差值或比率 | 公共基线柱形、点图、排序表 | 分母、单位、范围和排序必须一致 |
| 观察随时间的变化 | 时间序列、状态区间、局部趋势 | 折线、阶梯、采样点与趋势线 | 连线、窗口和平滑都包含时间假设 |
| 理解总体分布 | 样本、分箱、密度估计、分组统计 | 直方图、密度图、箱线或分组小图 | 分箱和带宽会改变呈现的峰形 |
| 探索两个或多个变量的关系 | 原始观测、相关或条件分组 | 散点、散点矩阵、平行坐标 | 相关、邻近和共现不自动构成因果 |
| 在无标签数据中寻找群体 | 标准化特征、距离、聚类 | 层次树、簇概览、特征轮廓、代表对象 | 群体依赖特征、距离与簇数，不是天然类别 |
| 理解高维对象 | 主成分、流形或邻域保持降维 | 低维投影与原对象、维度视图联动 | 投影只保留部分结构，簇间距离未必可比 |
| 把专业判断转成可复用条件 | 观察规则、分项指标、权重或查询树 | 指标矩阵、时间曲线、条件树 | 综合分数不能替代分项与规则来源 |
| 定位稀疏但有关联的事件 | 共同对象、时空窗口或关系网络 | 网络、邻接矩阵、时间视图与明细 | 聚合关系必须有明确对象和时间窗口 |
| 组织实体、属性与明确关系 | 三元组、模式、本体或知识图谱 | 节点链接、矩阵、层次或地理叠加 | 模型候选关系与逻辑证明是不同结果 |
| 查找多文档中的局部事实 | 分块、嵌入和相似性检索 | 命中文段、答案与来源链接 | 召回片段决定模型可见的证据范围 |
| 回答跨文档整体或关系问题 | 图索引、社区与分层摘要 | 主题概览、关系视图与证据下钻 | 增加的抽取和摘要成本要由查询需求支持 |

## 视觉编码

精确比较优先使用公共标度上的位置和长度。角度、面积、颜色深浅与立体体积适合表达大致差异或辅助属性，不承担相近数值的主要比较。

- 柱形图：比较类别数量，数值轴通常从零开始；柱宽保持一致。
- 堆叠柱形图：比较总量和构成；内部段缺少公共基线时，使用分组柱或分面进行精确比较。
- 散点图：每个点表示一次观测；用于关系、分群和离群点，不通过连线制造顺序。
- 折线图：顺序和区间内连续变化有意义时连接观测。
- 阶梯图：状态在变更前保持，跳跃表示生效时点。
- 直方图：区间面积或频数表达分布；不等宽箱以面积承担比例。
- 密度图：曲线下面积对应概率；带宽控制细节，纵轴与频数不可直接混用。
- 网络图：强调路径、邻域和局部关系；节点较多或需要精确查找时考虑矩阵、聚合或分层视图。

在关联视图中保持颜色、单位、时间范围、类别顺序和对象身份一致。时间窗口要包含理解事件前后所需的上下文。

## 带假设的转换

### 聚合

聚合提高可读性，也可能隐藏群体差异。保留样本量、分组字段和明细入口；当关键群体可能方向不同，进行分层或并列比较。

### 插值与拟合

插值描述观测点之间的假设，不增加采样证据。三次平滑可能生成原数据没有的峰、回摆或越界。拟合的模型复杂度和平滑范围决定趋势与噪声的取舍；同时显示采样点和关键参数。

### 分箱与密度

直方图的箱宽和边界、密度估计的带宽都会改变局部结构。比较能够代表粗、中、细尺度的设置，判断主结论是否稳定。

### 聚类

先统一量纲，再选择与任务匹配的距离。通过代表对象、维度贡献、群体规模和替代参数解释每个簇。业务含义无法稳定形成时，将其保留为探索结构。

### 降维

- 主成分分析优先保留线性方差，适合观察全局线性方向；
- 等距特征映射依赖合理的邻域图，尝试保留流形上的测地距离；
- t分布随机邻域嵌入强调局部邻域，簇间距离和面积不用于全局定量解释。

低维投影始终链接原对象、原维度或距离视图。

## 图形语义验收

把图表拆成数据、映射、统计变换、几何对象、标度、坐标系和分面。逐项回答：

1. 哪些数据行进入图形？
2. 字段经过了什么筛选、连接、去重、聚合或计算？
3. 每个变量映射到哪个视觉通道？
4. 图形几何是否表达当前任务？
5. 单位、标度、基线、时间窗口和分组是否可比？
6. 异常、峰值或关系能否定位到原始对象？

任何一项无法回答时，先修复图形声明或数据语义，再润色版式。
