# 可视分析闭环

把每项分析组织成“判断—表示—发现—解释—验证—行动”的闭环。图表是观察和追溯证据的接口；完成条件是结论能够回到数据对象，并改变一个明确的判断或行动。

## 工作流

### 1. 定义判断

把“分析一下数据”“做个大屏”或“找洞察”改写为一句任务定义：

> 谁在什么范围内，对哪些对象作什么判断，并据此执行什么动作？

明确使用者、对象、任务、时间与地域范围、分析粒度、行动入口和完成条件。若交付只是交流既有结论，也要明确读者应理解或比较什么。

**完成标准：** 任何拟展示的指标或模式都能对应到这句任务定义；无关内容退出主分析。

### 2. 建立数据语义契约

先确认一行记录代表什么，再计算指标。检查：

- 对象标识与可回查的原始记录；
- 发生时间、记录时间、生效时间和分析窗口；
- 字段类型、单位、枚举、分母、聚合口径和派生公式；
- 数据来源、采集过程、覆盖范围、缺失、重复和异常码；
- 筛选、连接、去重和分组会改变哪些对象。

对结构化数据先做与问题相关的数据质量检查。发现口径冲突时，分别呈现其范围；不同口径会改变主结论时，取得用户选择后再形成受影响结论。

**完成标准：** 每个关键指标都能追溯到原字段、对象范围、聚合方法和单位。

### 3. 选择表示与方法

选择能够保留任务所需差异的最简单表示。属性差异可用特征向量，时间变化可用时间序列，专业判断可用分项指标或规则，明确关系可用图结构，空间移动可用轨迹、网格或起讫矩阵。

当方法或图形选择并非显然时，读取 [方法与视觉编码选择](references/method-selection.md)。记录会影响结构的特征、距离、簇数、带宽、平滑范围、降维方法和随机性。

**完成标准：** 能够说明表示保留了什么、聚合掉了什么，以及如何返回原始对象。

### 4. 从概览进入细节

先用分布、时间变化、分组对比和基准建立概览，再按问题引入聚类、降维、预测、规则或关系分析。模型负责提出候选结构，视觉表达负责观察和比较，交互负责改变范围、参数与假设。

多视图应共享对象身份：从峰值、簇、区域、关系或残差选择对象后，在其他视图与明细中同步定位。聚合视图始终保留钻取到原表行、日志、原文、图片或视频时刻的路径。

将总体结果与关键分组并列检查。参数化转换至少比较一个有意义的替代设置；只有当替代设置可能改变当前判断时才扩大检查。

**完成标准：** 每个重要模式都已定位到具体对象，关键结论没有只依赖无法解释的投影或总量。

### 5. 建立证据链

将结果写成四层，保持层次独立：

| 层次 | 内容 |
| --- | --- |
| 观察 | 图形或计算实际呈现的数值、分布、峰值、簇、关系或残差 |
| 候选解释 | 哪种机制可能产生该模式 |
| 验证 | 支持或否定解释的原始记录、外部事件、实验、日志或专家复核 |
| 行动 | 证据将改变的查询、规则、资源配置、采集或系统操作 |

因果解释需要时间顺序、机制与替代解释的证据。当前材料只支持相关或共现时，把机制保留为候选解释，并给出最小验证动作。结论依赖现实事件、外部背景或当前事实时，核验相应的一手来源。

**完成标准：** 观察与解释没有混写；影响行动的解释有可定位的验证证据，或明确保持待验证状态。

### 6. 验收 AI 与图表产物

对人工和 AI 生成结果使用相同语义验收：

1. 数据对象与字段是否合法；
2. 筛选、连接、去重和聚合是否符合口径；
3. 图形类型与视觉编码是否支持目标判断；
4. 标度、基线、单位、时间窗口和分组是否一致；
5. 标签、注释和上下文是否足以独立阅读；
6. 选择路径能否回到原始记录。

代码可执行只证明执行链路成立。语义不符时，把反馈指向具体变换，例如“按用户去重后计数”“用同一纵轴范围比较各组”，再重新执行受影响步骤。

**完成标准：** 图形、查询或代码同时通过执行检查与数据语义检查。

### 7. 交付可复现的洞察

先给判断，再给支撑判断的证据。按任务规模组织以下内容：

- 问题、对象、范围与口径；
- 主要发现及其业务含义；
- 关键图表或视图，以及从概览到明细的阅读路径；
- 观察、候选解释、验证证据与行动建议；
- 数据版本、查询或代码、关键变换和参数；
- 未解释现象，以及会改变当前结论的新证据。

图表较多时，按照“总体状态—主要差异—对象细节—行动入口”安排层次。装饰服从信息；单位、基准、时间范围、样本量和必要注释保持可见。

**完成标准：** 读者无需猜测口径即可复核核心发现，能够定位证据并知道下一步行动。

## 返工信号

出现以下信号时，返回产生问题的步骤：

- 总体趋势与关键分组方向相反：返回数据语义与分组；
- 结论随分箱、带宽、窗口或聚合粒度轻微改变就反转：返回表示与参数；
- 簇、主题或低维投影无法由代表对象和原维度解释：返回特征与方法；
- 异常已定位但原因没有日志或外部事件支持：补充验证证据；
- 看板只能读数，不能钻取对象或进入处置：返回判断任务和交互路径；
- AI 结果能运行但字段、聚合或单位错误：返回数据语义契约并提供定点反馈。

完成整个任务前，逐项确认：判断明确、语义可追、方法匹配、对象可回查、解释有证据、结果可行动、过程可复现。
