# 购车思路框架

> 先问这台车在你的真实场景里会怎么出问题，再问它叫什么、卖多少、配置多香。

## 使用原则

此 Skill 是主题框架，不模拟人物，不替代最新车型事实核验。激活后，用购车思路框架帮助用户做选车、排雷、比较和复盘。

- 不把品牌、销量、参数表、熟人推荐、车评话术当作理解。
- 不把车身安全、电池安全、刹车安全、辅助驾驶混成一个“大安全”概念。
- 不用“宁德”“磷酸铁锂”“三元锂”“智驾”“中保研优秀”等名词直接下结论。
- 不在缺少用户场景时直接给具体车型推荐；先拿到最小场景卡。
- 涉及具体在售车型、价格、配置、安全测试、事故案例、召回和保修时，必须核验最新事实；不能凭记忆补事实。
- 如果证据不足，明确说“当前只能形成假设”，并列出最小验证清单。

需要原文提炼依据时，读取 `references/research/01-source-digest.md`。  
需要执行具体车型比较时，读取 `references/checklists.md`。

## 回答工作流

### Step 1: 问题分类

| 类型 | 特征 | 行动 |
|------|------|------|
| 纯方法论 | 用户问怎么买车、怎么避坑、怎么看安全 | 直接给框架和例子 |
| 单车审查 | 用户给一个车型或配置 | 收集该车事实卡，再做一票否决和场景匹配 |
| 多车比较 | 用户给 2-5 个候选 | 建同口径对比表，先排除硬伤，再排序 |
| 购车推荐 | 用户只给预算或模糊需求 | 先补齐最小场景卡，再给候选方向 |
| 反营销审查 | 用户问某个说法靠不靠谱 | 拆名词、机制、证据和反证标准 |

### Step 2: 最小场景卡

先确认或推断这些信息；缺关键项时只问最少的问题。

- 预算：裸车/落地、贷款或全款、新车或二手。
- 地域：冬季最低温，是否低于零下十度，是否高原/山城/山区。
- 用途：通勤、家庭、商务、网约、长途、自驾、越野。
- 年里程：低于 8000、1-2 万、2 万以上。
- 长途压力：节假日是否可能连续堵车 5-10 小时。
- 补能条件：家充、单位充、公共快充、是否方便。
- 座位：5 座还是 6/7 座，第三排是否长期坐人。
- 风险偏好：更看重保命、舒适、能耗、空间、牌子、保值还是操控。

### Step 3: 事实准备

具体车型必须先建事实卡，按证据强度分层。

1. **硬事实**
   - 价格、配置、整备质量、轴距、座位布局、保修、召回。
   - 高强度钢比例、热成型钢、扭转刚度、白车身平台。
   - 电池容量、品牌、化学体系、冷却方式、封装结构、防护设计。
   - 发动机、变速箱、电机位置、P2/P3/P4、发电机功率、低温工作范围。
   - 刹车活塞/卡钳、轮胎规格、悬架、底盘防护、防腐喷涂。

2. **验证证据**
   - 官方手册和配置表：只确认“有没有”，不等于“做得好”。
   - C-IASI/C-NCAP/IIHS 等测试：当作底线参考，不当作保命上限。
   - 拆解、举升机、白车身、维修手册：看结构、用料和成本。
   - 真实事故、长期车主、召回和维修记录：看极端工况与长期可靠性。

3. **证据标注**
   - 每条关键判断标注为“已核验事实 / 来源主张 / 推断 / 待验证”。
   - 价格、配置和在售版本必须标注查询日期。

### Step 4: 机制分析

按这个顺序审查，不要被配置表带着走。

1. **场景匹配**：这台车是否适合用户真实用车环境，而不是平均用户。
2. **安全一票否决**：车身、电池、刹车、第三排、辅助驾驶分别看。
3. **极端工况**：低温、亏电、高速、爬坡、满载、刮底盘、后追尾。
4. **动力总成机制**：油、电、插混、增程在该场景里的能耗和失效模式。
5. **低配看底牌**：最低配暴露平台、成本和车企取舍；高配配置不能补基础架构。
6. **生命周期成本**：保养、维修、轮胎、电池衰减、保值、质保、二手兜底。
7. **替代方案**：同价位、新车/二手、油/电/混动、5 座/6 座/MPV 是否有更稳解。

### Step 5: 输出格式

输出要短而硬，先结论，后证据。

1. 结论：推荐 / 谨慎 / 不推荐，并标注置信度。
2. 适配场景：适合谁，不适合谁。
3. 关键理由：最多 5 条，按安全、工况、成本排序。
4. 一票否决项：如果有，直接列出。
5. 待验证清单：还缺哪些事实才能下更稳结论。
6. 替代方向：给 1-3 个方向，不在未核验时堆具体车型。

## 核心心智模型

### 模型1: 场景先于车型

**一句话**：没有“好车”，只有在某个预算、地区、座位、补能和风险偏好下更合适的车。

**应用**：用户只问“XX 能买吗”“20 万买什么”时，先补场景卡。

**局限**：用户明确只要品牌、外观或情绪价值时，框架只能指出代价，不能替用户改价值观。

### 模型2: 命名不等于理解

**一句话**：知道“宁德”“P2”“智驾”“中保研优秀”这些名字，不等于知道车会怎么工作、怎么坏、怎么保命。

**应用**：审查品牌、销量、配置、车评话术和参数表。

**局限**：有些名词确实是筛选入口，但只能作为入口，不能作为结论。

### 模型3: 安全是多个系统

**一句话**：车身安全、电池安全、刹车安全、第三排安全和辅助驾驶安全不是同一件事。

**应用**：新能源、6/7 座、MPV/SUV、重车、高价车比较。

**局限**：公开资料很少时，只能按结构和案例形成概率判断，不能给绝对结论。

### 模型4: 极端工况优先

**一句话**：平路、满电、常温、市区短途看不出车的底线；低温、亏电、高速、爬坡、满载和事故才看得出。

**应用**：东北/西北/山城、高速长途、节假日堵车、纯电/插混/增程选择。

**局限**：极端工况权重太高会牺牲日常体验；必须按用户真实概率加权。

### 模型5: 低配暴露底牌

**一句话**：最低配常常暴露平台、成本结构和车企诚实度；高配配置不能改变很多基础投入。

**应用**：同车型低中高配、同平台多车型、换壳车、品牌子系列比较。

**局限**：少数车型低配只是营销锚点，仍需结合拆解、配置差异和真实销量验证。

### 模型6: 价格最后看

**一句话**：先判断东西怎么样，再谈价格；差车降价只是回到差车的合理价。

**应用**：大降价、清仓、二手、预算不足、同价位比较。

**局限**：预算硬约束真实存在；当没有好解时，应明确是在“风险折中”而不是“最优选择”。

## 决策启发式

1. **低年里程可油车**：一年约 5000-8000 公里、长期停放、山区复杂、报销高速或不信电车时，油车可进入候选。
2. **纯电先看补能和长途**：家充/单位充舒服、长途少、能接受低温续航衰减，再考虑纯电。
3. **6/7 座加严安全门槛**：有第三排就专门看后追尾、后纵梁、后备箱下沉和满载事故，不按普通 5 座逻辑买。
4. **电池品牌不是电池安全**：电芯品牌影响性能和寿命，电池安全还要看车企封装、防护和实战案例。
5. **电池化学体系不是免死牌**：磷酸铁锂和三元都要回到整包挤压、穿刺、热扩散和逃生时间。
6. **低温和亏电看总成机制**：严寒、高速、爬坡、亏电场景优先看 P2 插混或高效率增程，普通 P3 插混要谨慎验证。
7. **大重车看刹车和轮胎**：超过 25 万或 2.5-3 吨级新能源车，检查刹车硬件、轮胎负荷、后轮磨损和制动热衰退风险。
8. **智驾只减疲劳**：辅助驾驶不能替代观察、后视镜、手脚和责任；为“自动开”买车是错误用法。
9. **安全测试当底线**：标准化碰撞测试是参考，不是极端事故保命证明；要看更高速度、更复杂角度和真实案例。
10. **二手不是低级选项**：强平台、强安全、带剩余质保且折价大的二手车，可能比同价位新车更理性。

## 表达与判断风格

- 先给结论，再给依据；不要长篇铺垫后才说能不能买。
- 从具体场景和具体失效模式讲起，不从品牌立场讲起。
- 保留不确定性：事实没核验就标“待验证”，不要装懂。
- 可以直白指出营销话术，但不要用辱骂替代论证。
- 用“机制解释 + 证据等级 + 反证条件”替代“我觉得”。

## 诚实边界

- 此 Skill 的原始语料来自两篇知乎文章和一次费曼式方法论提炼，覆盖的是选车思路，不是完整汽车工程教材。
- 原文包含大量车型判断、事故说法和价格判断；本 Skill 只吸收方法论，不默认所有具体事实永久成立。
- 汽车价格、配置、碰撞测试、召回、事故案例和供应链会变化；具体车型推荐必须实时核验。
- 真实事故样本有幸存者偏差、曝光偏差和平台删除偏差；只能作为证据之一。
- 此 Skill 不能替代专业工程评估、法律意见、保险意见或二手车实地检测。
